# Kinship

Kinship is a personal CRM for staying close to the people who matter. It helps you organize contacts into relationship tiers, set check-in cadences, log interactions, keep notes, and schedule gentle reminders.

## What It Does

- Landing and auth flows for email/password and Google sign-in
- Authenticated app shell with desktop navigation and mobile bottom tabs
- Today dashboard with relationship nudges, upcoming reminders, tier counts, and recent interactions
- People directory with search, tier filters, and cadence health indicators
- Contact detail pages with profile data, quick interaction logging, timelines, reminders, notes, note history, and social/contact metadata
- Tier management for cadence names, colors, and check-in intervals
- Settings page for account info and planned channel integrations

## Tech Stack

- React 19
- TanStack Router and TanStack Start
- Vite
- TypeScript
- Tailwind CSS 4
- Supabase Auth and Postgres
- Lovable cloud auth for OAuth
- Cloudflare deployment support through Wrangler
- Radix UI primitives, shadcn-style UI components, Lucide icons, and Sonner toasts

## Getting Started

Install dependencies:

```bash
npm install
```

Create a local environment file:

```bash
cp .env.example .env
```

If `.env.example` is not present, create `.env` manually with:

```bash
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key

# Used by server-side rendering paths.
SUPABASE_URL=your_supabase_project_url
SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

Start the development server:

```bash
npm run dev
```

Then open the local URL printed by Vite.

## Supabase Setup

The app expects the schema in `supabase/migrations` to be applied to a Supabase project. The migrations create:

- `profiles`
- `tiers`
- `contacts`
- `interactions`
- `notes`
- `note_revisions`
- `reminders`

They also enable row-level security so users can only access their own data, create triggers for `updated_at`, create note revision snapshots on edit/delete, and seed default tiers when a new auth user is created.

For OAuth sign-in, configure Google authentication in Supabase/Lovable and make sure the redirect URL points back to the app, for example:

```text
http://localhost:5173/app
```

## Deployment

The project includes `wrangler.jsonc` for Cloudflare deployment with TanStack Start:

```jsonc
{
  "name": "tanstack-start-app",
  "compatibility_date": "2025-09-24",
  "compatibility_flags": ["nodejs_compat"],
  "main": "@tanstack/react-start/server-entry"
}
```

Set the Supabase environment variables in the deployment environment before building or publishing.
